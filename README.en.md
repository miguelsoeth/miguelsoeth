# Hi, I'm Miguel 👋

Full-stack developer. I work mostly with **C# / .NET** on the back end and **TypeScript (Angular)** on the front end, and now and then with **IoT**, from firmware all the way to the app.

## 🚀 Featured projects

### [ScreenCord](https://miguelsoeth.github.io/screencord/)
Windows desktop app for sharing your screen with friends, with Discord sign-in.
- **WPF / .NET 10** client, with its own **ASP.NET Core** API using **SignalR** and WebSocket media streaming
- Serverless **local rooms**, encrypted with TLS and certificate-fingerprint verification
- **MSI** installer (WiX), **auto-update** via GitHub Releases, and a UI in 3 languages
- CI/CD with GitHub Actions and tag-based SemVer

👉 [Download](https://github.com/miguelsoeth/screencord/releases/latest)

### BikeIOT
Bike-sharing system, from the hardware to the dashboard:
- [**Firmware**](https://github.com/miguelsoeth/BikeIOT-Firmware): C++ on the LILYGO T-A7670SA (4G), with MQTT telemetry and BLE unlocking
- [**API**](https://github.com/miguelsoeth/BikeIOT_API): ASP.NET Core, JWT, EF Core, MQTTnet, short-lived unlock signatures and geofencing
- [**App**](https://github.com/miguelsoeth/BikeIOT.App): Ionic + Angular + Capacitor; finds bikes over Bluetooth, unlocks and locks them
- [**Admin dashboard**](https://github.com/miguelsoeth/BikeIOT.Adm): Angular 21, geofencing map with Leaflet, and telemetry

### Distributed systems with gRPC
- [**GrpcBackup**](https://github.com/miguelsoeth/GrpcBackup): file and folder backup, with a gRPC client and server
- [**Sincronizador.gRPC**](https://github.com/miguelsoeth/Sincronizador.gRPC): file synchronization between two nodes
