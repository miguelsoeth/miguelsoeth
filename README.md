# Olá, eu sou o Miguel 👋

Desenvolvedor full-stack. Trabalho principalmente com **C# / .NET** no back-end e **TypeScript (Angular)** no front, e de vez em quando com **IoT**, do firmware até o app.

## 🚀 Projetos em destaque

### [ScreenCord](https://miguelsoeth.github.io/screencord/)
App desktop para Windows de compartilhamento de tela entre amigos, com login pelo Discord.
- Cliente em **WPF / .NET 10**, API própria em **ASP.NET Core** com **SignalR** e mídia por WebSocket
- **Salas locais** sem servidor, cifradas com TLS e certificado conferido pela impressão digital
- Instalador **MSI** (WiX), **atualização automática** pelas GitHub Releases e interface em 3 idiomas
- CI/CD com GitHub Actions e versionamento SemVer por tag

👉 [Baixar](https://github.com/miguelsoeth/screencord/releases/latest)

### BikeIOT
Sistema de bikes compartilhadas, do hardware ao painel:
- [**Firmware**](https://github.com/miguelsoeth/BikeIOT-Firmware): C++ no LILYGO T-A7670SA (4G), com telemetria via MQTT e desbloqueio por BLE
- [**API**](https://github.com/miguelsoeth/BikeIOT_API): ASP.NET Core, JWT, EF Core, MQTTnet, assinatura temporária para o desbloqueio e geofencing
- [**App**](https://github.com/miguelsoeth/BikeIOT.App): Ionic + Angular + Capacitor; encontra as bikes por Bluetooth, desbloqueia e trava
- [**Painel admin**](https://github.com/miguelsoeth/BikeIOT.Adm): Angular 21, mapa de geofencing com Leaflet e telemetria

### Sistemas distribuídos com gRPC
- [**GrpcBackup**](https://github.com/miguelsoeth/GrpcBackup): backup de arquivos e pastas, cliente e servidor em gRPC
- [**Sincronizador.gRPC**](https://github.com/miguelsoeth/Sincronizador.gRPC): sincronização de arquivos entre dois nós
